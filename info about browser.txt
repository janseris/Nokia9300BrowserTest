Info about phone:
- Nokia 9300 (9300i is model with Wi-Fi, 9500 is larger model with camera and larger battery
- 150 MHz CPU
- GPRS 2G mobile connection

Info about browser:
Opera 6.x browser with smart rendering
- calling itself Mozilla4.0 in User-Agent string
- reporting itself as MSIE (Internet Explorer) 5.0 compatible in User-Agent string

Reported features from Nokia 9300 technical and product documentation:
- HTML 4.01
- XHTML
- JavaScript 1.3
- WML 1.3
- Flash 5 (according to 9300 User Guide), Flash 6 (according to 9300i User Guide)
- cookies
- TLS 1.2 support via GitHub project Symbian TLS/BearSSL for EKA1 kernel Symbian s80
  - supports HTTPS
  - does not check certificates
  - no planned support for TLS 1.3
- multiple windows

Info from tests:
- cookie HttpOnly doesn't work - Javascript could read this cookie
- cookie SameSite=Strict no (introduced in 2016 to prevent CSRF attacks, can be fixed using CSRF tokens probably)
- cookie Secure OK - the cookie is only used in HTTPS and is not sent back if connecting to HTTP
